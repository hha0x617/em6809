# メモリダンプ編集 UI 設計（案）

本書は「メモリダンプペインでメモリの値を更新する」機能の UI/実装方針をまとめたものです。既存のレジスタ編集 UI と整合し、MMU 保護・書き込み追跡・パフォーマンスに配慮します。

## 目的と範囲

- 目的: GUI のメモリダンプから 1 バイト単位で値を編集し、エミュレータのメモリへ反映できるようにする。
- 範囲: ロジカル 64KB メモリ空間への書き込み（`Memory` または `Mc6829` を透過）。MMU の保護設定は尊重し、強制書き込みは行わない。

## ユーザー体験（UX）

- 編集モード切替: メモリペインのヘッダーに「編集」トグルを追加。ON で編集 UI を有効化。
- 編集単位: 1 バイト編集を基本。
  - Hex 側セル: 2 桁 Hex の小型 TextEdit（Enter で確定、Esc でキャンセル）。
  - ASCII 側セル: 1 文字入力（非表示は '.'）。
- 一括操作（段階導入）:
  - 貼り付け（Hex/テキスト）: モーダルで入力 → 指定アドレスからステージング。
  - 塗りつぶし: 選択範囲に同一値を一括設定（任意）。
- 適用フロー:
  - ステージ（未適用）→ 適用（Apply）→ バスへ write8。Cancel で全破棄。
  - 「ライブ適用」ON（任意）でセル確定時に即 write（既定は OFF）。
- フィードバック:
  - ペンディング編集を黄色、保護等で失敗した箇所を赤でハイライト。ツールチップで理由を表示。
- ナビゲーション: 矢印/Tab でセル移動。Home/End で行頭/行末。Shift で選択拡張（拡張時）。
- 追従: 「PC 追従」ON 時も、編集中セルが視界外へ移動しないようスクロールを抑制。

## 状態とデータフロー（regview）

- 追加状態（RegApp）:
  - `mem_edit_mode: bool`（編集 ON/OFF）
  - `mem_live_apply: bool`（セル確定で即 write）
  - `mem_pending: HashMap<u16, u8>`（未適用差分）
  - `mem_selection: Option<u16>`（選択中アドレス）
  - `mem_error: Option<String>`（直近のエラー表示）
  - `mem_undo: Vec<Vec<(u16, u8)>>`（バッチ単位の Undo）
- 描画:
  - 通常は Label。選択セルのみ TextEdit（Hex2 桁）/ASCII 1 文字に差し替え。
  - ペンディングのバイトは Hex/ASCII 両側で色付け表示。

## コマンド拡張（regview → main）

- `enum Command` へ追加:
  - `MemWrite(Vec<(u16, u8)>)`（Apply で一括書き込み）
  - `MemWriteLive(u16, u8)`（ライブ適用）
  - `MemPaste(Vec<u8>, u16)`（指定アドレスから貼り付け）
- 戻り値は不要（UI は次回読み出しで反映可否を判断）。必要に応じてエラーカウント返却を検討。

## main 側の処理（Pause 中のみ適用）

- Pause 中のコマンド処理に上記コマンドを追加。
- ラン中は Apply/Live を無効化（UI 側でボタン非活性）。
- `Bus` は `IoBus<Memory|Mc6829>` または `WriteTrack(IoBus<...>)` の可能性があるため、既存の downcast パターンで最終的に `write8` を呼ぶ。
- 適用後、既存のメモリビュー更新ロジックによりウィンドウを再描画。

## 保護・失敗時の扱い（MMU 等）

- `Mc6829` の WPROT/RPROT/NX を尊重。
  - WPROT ヒット: 実メモリは書き換わらない → 次回読み出しで差分が消える。
  - UI は Apply 後に未反映の箇所を赤表示し、ツールチップで「書き込み不可ページ」を示す。
- 64KB 外は対象外。表示窓外への編集はアドレスで保持し、適用可能。

## パフォーマンス配慮

- TextEdit は選択セルのみ。大半は Label で描画して負荷を軽減。
- 貼り付けは上限（例: 4KB）を設ける。
- Apply は連続 write8 で問題なし（WriteTrack が差分検出）。

## キーバインド（Hex 編集）

- 許可文字: 0–9, A–F。Backspace で取消、Enter で確定、Esc でキャンセル。矢印で隣接セル移動（拡張時）。
- ASCII 編集: 印字可能 1 文字。Backspace は取消。

## 実装段階

- フェーズ 1（最小）:
  - 「編集」トグル、Hex セルのインライン編集、Apply/Cancel（Pause 中のみ有効）。
  - ライブ適用（任意）と Undo（直前バッチのみ）は後追い。
- フェーズ 2（拡張）:
  - ASCII 側からの編集、貼り付け（Hex/テキスト）、Undo スタック、範囲一括操作。

## 変更箇所（概要）

- `src/regview.rs`:
  - RegApp にメモリエディット用の状態を追加。
  - メモリペインでセル選択/インライン TextEdit/ペンディング管理、Apply/Cancel/ライブ適用ボタンを実装。
  - `Command` にメモリ系コマンドを追加。
- `src/main.rs`:
  - Pause 中のコマンド処理に `MemWrite` 等を追加し、`Bus::write8` を呼び出し。
  - 適用後にメモリウィンドウの即時更新（既存の更新ロジックを利用）。

## ガード・ポリシー

- Pause 中のみ適用を許可（Run 中は UI 側で非活性）。
- MMU 保護は尊重（強制書き込みは行わない）。
- レジスタ編集と同様に Edit/Apply/Cancel の語彙・色分けを踏襲。

***

本設計は既存の Viewer/Command/Bus の構造に自然に合致し、段階的導入が可能です。フェーズ 1 を短期間で提供し、ユーザーのフィードバックに基づきフェーズ 2 を拡張していきます。
